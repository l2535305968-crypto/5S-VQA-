# VQA 实操补充规则（v2.1 精简版）

> **核心原则**：创作规划用 **5S**；审核结论用 **分级模式 + 离散评级 + 证据门禁**，不为了填表而制造噪音。本规则作为 `VQA_专业图像质量审核规范_V2.0.md` 与 `5S_VQA_协同调用规范.md` 的实操补充，在冲突时优先用于日常执行效率与防误判控制。

## 1. 三档审核模式（按需触发）

| 模式 | 适用场景 | 必做动作 | 输出形式 |
|---|---|---|---|
| **Lite（快速迭代）** | 抽卡选方向、草稿微调、单轮改图 | 仅查 `S1` 主体、`S2` 风格、`S3` 结构硬伤 | 1–3 条可执行改图指令，**不打分、不填表、不建 Profile** |
| **Standard（单图验收）** | 单张成品定稿、准备超分或精修前 | 运行 `image_qc.py` + 查看主体 `1:1` 裁切 + P0/P1 清单 | 精简结论 + 缺陷列表 + 下一步动作 |
| **Strict（商业/系列交付）** | 多图一致性、商业交付、正式入库 | 全套 `Q1–Q7` 审核 + 跨图锚点核对 + `SHA256` 溯源 | 完整审核报告 + 交付记录 + 必要时建 `Profile` |

---

## 2. Q1–Q7 离散评级（替代百分制）

取消 `0–100` 绝对打分与加权总分，统一采用 **4 档离散评级**，由 **硬闸（P0）+ 关键缺陷（P1/P2）** 直接决定结论：

- **PASS（通过）**：符合要求或仅存在当前用途可忽略的细微瑕疵。
- **MINOR（轻微瑕疵）**：存在 P2 级局部问题，视使用场景决定是否修复。
- **MAJOR（明显缺陷）**：存在 P1 级结构/身份/伪纹理/风格偏差，需返工。
- **BLOCK（阻断失败）**：存在 P0 级硬性违反（主体错误、文字错误、技术规格未达、文件损坏）。

> 多张候选图需要“矮子里拔将军”时，仅做 **相对排序（候选1 > 候选2）**，不虚构绝对分数。

---

## 3. 交付状态与阶段切分

将“方向可用”与“终稿技术达标”解耦，避免把优质低分辨率草稿直接判死：

- **`APPROVED`**：视觉质量（`VISUAL_PASS`）与技术规格（`PIXEL_PASS` + 格式）全部达标，可终稿交付。
- **`CANDIDATE_PASS`**：构图、主体、风格均合格，但像素尺寸或后期封装未达终稿标准；**允许作为母版进入超分/精修/排版流程**。
- **`REVISE`**：存在可定向修复的局部结构、光影或细节缺陷（`P1`/`P2`），按《5S→VQA 返工映射》局部修改。
- **`REJECTED`**：方向、主体、核心约束或比例严重错误（`P0`），建议更换源图或重新生成，不继续修补。
- **`UNVERIFIED`**：缺少原图、裁切证据或关键参数，暂无法定论。

---

## 4. 视觉核验的“真 E2”门禁

由于多模态模型读取整张高分辨率大图时通常会被自动缩放，因此将 **E2** 拆分为两项硬条件：

1. **E2-Tech（技术核验）**：已通过 `image_qc.py` 读取真实宽高、格式、Alpha/ICC 元数据。
2. **E2-Visual（像素核验）**：视觉模型已实际查看 `review_100pct_crops.png` 或针对人脸、手部、文字、Logo 的 `--focus` `1:1` 原像素裁切。

> **门禁规则**：未完成 `E2-Visual` 时，**禁止**对 `Q5（表面细节）` 与 `Q6（N1–N4 伪影）` 做出“细节完美/无伪影”的确定性判断，统一标注为 `未核验 1:1 细节`。

---

## 5. 细节与风格判定边界

- **观看距离原则**：`1:1` 裁切用于拦截主体硬伤和全局压缩/过锐化（N3/N4）。对于远景树叶、地面砖石、背景饰纹的轻微 N2 融合，须结合最终用途（如手机屏保、网页缩略图、印刷海报）判断是否构成需修复缺陷，避免无限局部返工。
- **Style Registry 启用边界**：仅在 **系列多图、固定 IP、长期复用风格** 时建 JSON Profile；单次探索性创作直接用 **5S 的 S2（风格统一性）** 锁定视觉语言与 N5 有意纹理即可，不强制生成 `Temporary/*.draft.json`。
- **三轮止损**：同一修复路径连续 `3` 次未解决或引入新崩坏，立即停止迭代，回滚 `source_master` 并切换策略（改原图重绘 / 换工具 / 拆分局部蒙版）。
