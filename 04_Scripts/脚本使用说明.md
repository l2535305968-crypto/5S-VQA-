# image_qc.py · 技术审核工具说明 v2.0

## 0. 边界

本脚本可以读取文件元数据、像素尺寸、文件SHA256、EXIF方向、ICC存在性、Alpha/透明通道范围，裁切原像素100%对照图，生成JSON/TXT报告，批量导出CSV/JSON汇总。含透明通道的预览接触表会叠加棋盘格背景，避免直接丢弃Alpha后误读透明边缘；单独focus裁切保留原始Alpha。不能自动证明“原生4K”，不能恢复真实细节，不能通过数值自动判断画面是否好看、是否有AI伪纹理、风格是否正确或文本是否准确。这些必须由VQA视觉审核完成。

要求 Python 3.10+ 和 Pillow。可选 `jsonschema` 用于风格库完整Schema校验。不要为了运行脚本擅自安装依赖；先检查本机环境。

## 1. 常见命令

```powershell
# 必须用输入文件的真实路径；显式指定交付尺寸。
python 04_Scripts/image_qc.py "C:\images\image.png" --target 2160x3840 --format PNG

# 旧命令兼容，仍会正确检查横屏3840x2160
python 04_Scripts/image_qc.py "C:\images\wallpaper.png" --target 3840x2160

# 不指定 --target 时只收集技术信息与裁切图，显示 NOT_EVALUATED，禁止宣称尺寸验收通过。
python 04_Scripts/image_qc.py "C:\images\art.png"

# 文件夹批量检查（子文件夹也包含），结果写入 reports/
python 04_Scripts/image_qc.py "C:\images\" --recursive --target 2160x3840 --out "C:\reports\"

# 指定感兴趣区域：从左上角(120,200)裁切384x256原像素，不缩放。
python 04_Scripts/image_qc.py "C:\images\image.png" --target 2160x3840 --focus 120,200,384,256

# 与原始母版进行技术尺寸对比（不宣称真实细节恢复）
python 04_Scripts/image_qc.py "C:\images\final.png" --baseline "C:\images\original.png"

# 注册表检查
python 04_Scripts/validate_registry.py
```

Linux/macOS终端使用普通路径即可，`python`可替换为`python3`。

## 2. 输出文件

单图：`qc_<stem>/report.json`、`REVIEW.txt`、`review_100pct_crops.png`，额外 `--focus` 会输出 `focus_01_100pct.png` 等。批次：每图独立文件夹，同时提供 `summary.json`、`summary.csv`。

主要字段：`actual_size_px`, `required_size_px`, `pixel_requirement`, `format_requirement`, `technical_status`, `visual_quality_status`, `source_native_resolution`, `processing_history`, `source_sha256`, `has_alpha_channel_or_transparency`, `alpha_extrema_0_255`, `inspection_crops`, `focus_crops`。

结果含义：
- `TECHNICAL_PASS_VISUAL_PENDING`：尺寸/格式等指定的技术闸门通过；视觉质量仍未审核。
- `FAIL`：至少一项指定技术闸门失败。
- `INSPECTION_ONLY`：用户没有指定目标尺寸或格式，仅收集信息。
- `NOT_EVALUATED`：该项未给出验证要求或证据。

程序退出码：0 = 本次已指定的技术项无失败（**不是视觉通过**），2 = 技术门槛失败，1 = 文件/读图异常或部分检查失败。

## 3. 100%裁切注意事项

检查区域中的每一个像素等于原文件一个像素；接触表只是把原像素排列到新画布，没有重采样，但查看软件的屏幕缩放可能影响观看，请在100%显示。裁切检查不一定覆盖最重要的主体，审核者必须主动添加重点区域。大图检查可以增加局部位置；不得把程序的噪声警告当作艺术质量评分。

## 4. 放大与源生声明

脚本只能证明最终文件实际尺寸，不知道模型初次生成的真实尺寸。要确认“原生4K”必须提供模型生成日志或可验证记录。只有最终4096x4096但原图为1024x1024的作品，应标“放大成品”，不论使用插值还是AI超分；AI超分可以补推测纹理但需要真实性对照。

## 5. 版本兼容

旧版 `python scripts/image_qc.py <file> --target 3840x2160` 的调用参数保留。唯一有意的安全行为变更：**没有 `--target` 不再暗自假定3840x2160**，而是“未核验尺寸”。这是为了避免竖屏、方形或任意未来画幅误判。
